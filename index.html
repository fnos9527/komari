掌握 DeepSeek Harness
构建你的专属 AI 智能体工作流

DeepSeek Harness（dsh）是一个开创性的开源 AI Agent 运行时。模型只是大脑，而 Harness 赋予它工具、沙箱、会话记忆与强大的插件生态。

一键开始安装 探索十大必装插件
bash — dsh web
# 安装 Node.js 后直接在终端运行以下命令：
$ npx @deepseek-ai/dsh web
[Cordis Kernel] Initializing plugins...
[DSH Web Server] Running local Web UI at http://127.0.0.1:3080

为什么选择 DeepSeek Harness？

告别臃肿且封闭的固定编码助手，拥抱基于 Cordis 内核的模块化架构。

一切皆插件

模型、工具、技能、会话、沙箱、存储甚至 UI 都可以作为可替换的插件加载。通过 YAML 配置文件灵活编排，无需修改源码。

模型无关性

完美支持 DeepSeek、Anthropic、OpenAI、Amazon Bedrock 以及任何兼容 OpenAI 接口的端点。自由切换模型，而运行逻辑保持不变。

会话与轨迹视图

每个运行状态都记录在追加写入的会话日志中，支持会话恢复、分叉（fork）、搜索、重放及直观的轨迹视图。

Installation Guide

保姆级安装教程

仅需几个简单步骤，即可在本地搭建功能强大的 DeepSeek Harness 开发环境。

1

安装 Node.js 环境

DeepSeek Harness 依赖现代 Node.js 运行环境，推荐使用 LTS 版本 (Node.js 20+)。

node -v # 验证版本 >= 20 官网下载
2

全局安装 Harness 与包管理器

安装核心 CLI 工具以及插件管理所需的 pnpm。

npm install -g @deepseek-ai/dsh pnpm
3

配置 API 密钥环境变量

设置您的 DeepSeek API Key（也可在网页端设置）。

export DEEPSEEK_API_KEY="your_key_here"
4

启动本地 Web UI 界面

执行命令启动内置服务器，并在浏览器访问 http://127.0.0.1:3080。

npx @deepseek-ai/dsh web
Ecosystem & Extensions

DeepSeek Harness 十大必装插件

精选扩展插件，全面提升开发工作流、界面体验、持久化记忆与多模态能力。

UI 扩展

1. dsh-web 工作空间增强

扩展官方 Web 档案，集成任务管理、移动端适配、SSH 远程操作、Git 可视化及资源监控面板，将复杂工作流整合至统一面板。

dsh plugin add @dsh/web-ext
开发效率

2. DSH-better-sidebar 侧边栏工作台

将原生侧边栏转变为全功能开发工作台，完美嵌入文件树、编辑器、Git 活动监控、内置终端及网页预览，减少 supervision 摩擦。

dsh plugin add @dsh/better-sidebar
终端控制

3. dsh-TUI 终端优先界面

为 DeepSeek Harness 提供类似 Claude Code 的终端前端，支持流式 Markdown、工具调用卡片、会话恢复与上下文状态显示。

dsh plugin add @dsh/tui
智能记忆

4. OpenViking Memory 跨会话持久记忆

打破会话隔离，为 Harness 注入持久化记忆基础设施。自动召回项目架构决策、开发偏好与历史经验，使长周期研发更加连贯。

dsh plugin add @openviking/memory-bundle
多模态

5. ModLens 多模态视觉理解插件

通过接入视觉后端，为智能体赋予强大的图片读取与 UI 审查能力。支持上传截图、分析前端布局并生成精准修改建议。

dsh plugin add @liustack/modlens
安全隔离

6. dsh-sandbox-docker 容器沙箱

提供基于 Docker 的安全隔离执行环境。智能体运行高危命令或测试脚本时，自动在隔离沙箱中执行，保障宿主机系统安全。

dsh plugin add @dsh/sandbox-docker
多智能体

7. dsh-subagents-bridge 子智能体桥接

允许将 Claude Code、Codex 等其他外部 AI Harness 作为子插件接入，构建由 DeepSeek 统筹的多智能体协作流水线。

dsh plugin add @dsh/subagents-bridge
版本控制

8. dsh-git-flow Git 智能管理插件

自动化处理分支创建、智能 Commit 消息生成、冲突检测与 Pull Request 提交流程，让智能体深度参与团队 Git 规范。

dsh plugin add @dsh/git-flow
监控分析

9. dsh-telemetry-metrics 成本分析面板

实时追踪每次会话、每个工具调用的 Token 消耗、API 延迟与费用开销，提供直观的可视化图表，帮助开发者优化提示词与成本。

dsh plugin add @dsh/telemetry-metrics
个性美化

10. dsh-theme-matrix 主题矩阵

为 Web UI 带来丰富的主题定制能力，包括赛博朋克霓虹、极简北欧暗夜、高对比度终端绿等多种精美视觉方案，打造沉浸式编码氛围。

dsh plugin add @dsh/theme-matrix
Runtime Profiles

四大核心运行模式

DeepSeek Harness 内置四种预设模式，适配从日常编码到定制智能体开发的各种场景。

Standard 模式

标准的智能体编码助手配置，平衡了工具访问与自主性，适合日常全栈开发与 Bug 修复。

PTC 模式

针对复杂重构与架构规划优化，赋予模型深度推理与多步计划验证能力。

Minimal 模式

极致轻量化，仅保留基础 bash 和文件编辑器工具，最适合基准测试与模型效果评估。

Creator 模式

面向智能体构建者的扩展模式，允许自由组装新插件、调试底层 Cordis 内核事件与服务。
